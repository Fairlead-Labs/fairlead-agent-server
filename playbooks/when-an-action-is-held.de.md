# Wenn eine Aktion zurückgehalten wird
Was geschieht, wenn ein Dienst einen Aufruf für eine Person zurückhält.

- Ein zurückgehaltener Versand, Termin oder Abschluss wartet beim Dienst auf eine Person. Ihr Lauf wartet dort und geht mit dem Ausgang als Ergebnis dieses Aufrufs weiter.
- Erledigt: die Aktion wurde ausgeführt. Abgebrochen: eine Person hat sie abgelehnt oder sie ist abgelaufen; lesen Sie warum und überarbeiten Sie danach. Fehlgeschlagen: sie wurde nicht ausgeführt.
- Wiederholen Sie einen zurückgehaltenen Aufruf nie, solange er wartet, und suchen Sie keinen Weg um die Freigabe herum.
