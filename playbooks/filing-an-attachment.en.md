# Filing an attachment to a project
How to file a mail's attachment in a project's folder.

- Find the message and its attachment; check the name and type before you file it.
- Save it with `save_attachment_to_project` into a folder your grant allows; if the name exists, add a version instead of a copy.
- Link the file to the task where it belongs (`link_file`).
- Name the file and folder in your result.
