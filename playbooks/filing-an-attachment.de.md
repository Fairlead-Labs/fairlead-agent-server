# Einen Anhang im Projekt ablegen
Wie Sie den Anhang einer Mail im Ordner eines Projekts ablegen.

- Suchen Sie die Nachricht und ihren Anhang; prüfen Sie Name und Typ, bevor Sie ihn ablegen.
- Speichern Sie ihn mit `save_attachment_to_project` in einem Ordner, den Ihre Berechtigung erlaubt; gibt es den Namen schon, legen Sie eine Version statt einer Kopie an.
- Verknüpfen Sie die Datei mit der passenden Aufgabe (`link_file`).
- Nennen Sie Datei und Ordner in Ihrem Ergebnis.
